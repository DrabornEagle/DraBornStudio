Three shelves. One memory.

From quick copy to a lasting collection.

Use the shelves for the next thing you need. Use Library for the things you want to keep. Pinning, folders and tags bridge the two without creating a second set of favorites.

Your first five minutes

  1. Install and open

    Download the latest Mac release, move the app to Applications and open it. clipboard-app lives in the menu bar.

  2. Choose what to collect

    In Settings → Sources, enable image or text capture if wanted. Standalone-link capture defaults on and can be disabled. Choose screenshot handling separately.

  3. Browse without breaking your flow

    Press ⌃⌥T, use the arrow keys and press Space to preview. Enter copies and closes the shelves; focus returns to the previous app.

  4. Keep the useful things

    Press P to pin, ⇧P to choose a folder or ⌥P to add a useful name. Tagged or filed records remain after normal history expires.

  5. Make it your own

    Set retention for each content type, record shortcuts, choose colors and toggle automatic update checks in Settings.

Full feature inventory

Everything the app does, in one place.

This inventory describes the 1.7.3 source implementation. The latest release lists available packages and validation evidence; native platform details are listed in the comparison. Features below describe the application, not a promise that every receiving app supports every clipboard representation.

01

Three independent shelves

Browse Images, Texts and Links as separate horizontal rows. Toggle each row, switch the active shelf, filter pinned items and scroll through older copies. Opening selects only the first available image; if Images is hidden or empty, the first available item in the next visible shelf is selected.

02

Screenshot and clipboard capture

Handle screenshots instantly, watch up to three additional image folders, and optionally collect copied images or text. Clipboard image and text collection are independent opt-ins. Text and link copies arrive silently without opening the shelves.

03

A local Library

A normal resizable window with grid and column-based list views, a folder/tag sidebar and an auto-saving editable inspector. Create notes, edit titles and content, and organize images, text and links together. Full screen is optional.

04

Pin, name, file and tag

Pin and favorite are one action. Pins, folder membership or tags retain an item beyond ordinary history expiry. Use nested virtual folders and multiple tags; name-and-pin supports a sequential batch workflow.

05

One shelf search

The centered search field searches all currently visible shelves: text, link details, titles, notes, tags and recognized text in images. Hidden shelves are excluded. Browse results without opening Library.

06

OCR and visual search

OCR runs locally through Apple Vision on Mac and packaged English/Turkish Tesseract on Windows. Both use the original MobileCLIP-S2 model for offline Library visual search, with text/OCR, visual and combined modes plus type, date, domain, tag, folder and pinned filters. Visual descriptions work best in English.

07

Link cards with context

A standalone copied web URL goes to Links; a paragraph containing URLs stays text. Optional enrichment adds website or YouTube titles, authors and thumbnails. Open the selected link in your browser.

08

Borderless previews

Space opens images, editable text and link previews. Shelf previews can move across content types without closing the window. Image zoom runs from initial fit to 400%; pinch, wheel and drag-to-pan are supported.

09

Editable markup and crop

Pen, translucent marker, rectangle, ellipse, arrow, line and text tools share the top preview toolbar. Move/resize marks, change styles and undo. Crop non-destructively; original files and editable annotations remain available.

10

Copy, paste, drag and export

Copy selected batches in order, drag multiple items, export copies, or explicitly paste into the editable field previously focused in another app. Image copies include full-resolution crop/markup. Multiple-image paste depends on the destination app.

11

History without repeated text cards

Configure image, text and link retention separately: 1, 3, 7, 15 or 30 days, with 30 days as the default. Re-copying equivalent text refreshes one current entry instead of filling the shelf with duplicates; saved organization is preserved.

12

Take down and recover

S removes the selection and selects the next surviving item. Saved records remain in Library; temporary copies enter recoverable Trash. Backspace restores the latest shelf removal, including batches, during the current app session. External original files are preserved.

13

Keyboard-driven Actions

Search the contextual Actions bar for organization, navigation, image editing, Library views, settings and updates. Commands show current shortcut assignments and operate on the item or ordered batch captured when the bar opened.

14

An interface you can tune

Small, medium and large cards; soft shelf colors or neutral glass; configurable reveal behavior, full-screen-app visibility, sounds and login launch. Choose the app language independently of the system. Browsing bindings, selection keys and global shortcuts can be remapped or disabled.

15

Native signed updates

Mac uses Sparkle; Windows uses its signed installer feed. Official public updates need no GitHub account or token. Automatic checks can be disabled; when enabled they run hourly while the app is running. Download and installation require your action.

16

Screen recordings

MP4/MOV recordings stay in Images. Windows 1.7.3 adds file import/watching, playback, M/Actions Trim and file copy/drag/export through native Windows media APIs. Native acceptance is mandatory before publication; codec and trim differences are documented below.

Windows interface and updates — 1.7.3

Mac-like hanging shelves and normal Library/Settings windows, verified in actual Windows sessions.

Hanging shelves over your desktop

Images, text and links hang from three curved ropes on a transparent desktop surface. Aspect-fit image frames preserve wide or portrait screenshots; row controls stay compact. A plain shelf click copies and keeps browsing open. Turn on Select items or hold Ctrl/Shift to select only; clicking an empty shelf area hides the shelves.

A normal Library and Settings workspace

Library opens in a resizable window with minimize, maximize and close controls. Its unified toolbar offers search, view and filter controls plus sidebar/inspector toggles. Neutral grid/list cards show media, type and tags. Settings uses a branded sidebar and grouped controls; full screen is not forced.

One centered search and Actions language

Shelf search floats in the center with visible-type chips and a result count. Enter or Up/Down leaves text entry for result navigation; the applied query remains as a compact summary. Actions uses the same visual language and centered shortcut badges.

Preview without breaking your flow

Space previews the focused item. Arrow keys change content in place; the top row combines navigation with markup/crop tools while keeping navigation accessible. Enter closes shelf-origin browsing after copying; Library and Library-origin previews stay open.

Pages sized to the visible shelf

Alt+Left/Right advances by the number of cards that fit, up to nine, based on window width and card size. Number keys select the cards actually offered on that page. Library uses its actual grid columns for Up/Down and nine-result Alt jumps.

Check automatically, install deliberately

When enabled, update checks are scheduled after launch when due and hourly while running; failed checks retry after five minutes. New versions appear in the tray, shelf badge and Updates page; notifications open that page. Checks never install. Click Update and reopen to download, verify the signed manifest and installer hash/size, replace the app and reopen it. Existing Library/settings are retained, and no GitHub token is required.

Windows implementation and validation guide

Local collection. Explicit connections.

Stored on your Mac

History, folders, tags, notes, thumbnails and search indexes live locally. clipboard-app does not provide cloud sync. Local storage is not a password vault; choose what you copy and retain.

Image and text capture are opt-in

Turning a watcher on skips the previous clipboard contents. Concealed, transient and autogenerated clipboard markers are checked, Finder file copies are skipped, and the app suppresses its own copies.

OCR and visual search stay on-device

Image recognition, visual embeddings and search queries run locally. Runtime OCR/visual search does not upload images or query text.

Link enrichment is optional network access

Enabled enrichment contacts the linked website or YouTube for metadata and thumbnails. Local addresses and URLs with known secret parameters are excluded; disable enrichment in Sources if unwanted.

Updates use the network, not a client token

The official Sparkle feed and archives are public and signed. Checks are configurable; downloads and installation need your action. This update channel does not require a GitHub login.

Paste has a separate permission

⌘Enter needs the app’s macOS Accessibility permission. It validates the original editable field and refuses secure or changed targets. Ordinary copying does not require that permission.

Recoverable removal, preserved originals

Temporary records can be recovered from Library Trash. External source images are not deleted by taking them off the shelf. Expiry is separate for images, text and links.

Native Mac. Separate Windows edition.

The current application uses Swift, AppKit, SwiftUI, Vision and Core ML. It supports macOS 14 or later on Apple silicon and Intel. A separate Electron Windows x64 edition is also available; support gaps and native validation evidence are explained below.

Built on real shoulders.

clipboard-app is a modified fork of Tendedero by Alejandro Buján, based on upstream 1.5.0. Tendedero is the actual MIT-licensed source upstream; its copyright and contributor acknowledgements remain. clipboard-app uses its own name and artwork and is not endorsed by the original author.

Inspired by Tendedero, clipboard-app extends its clipboard workflow with a local Library, shared OCR search, pinning and naming, folders and tags, editable image markup and crop, keyboard navigation and public signed updates.

Sparkle provides the updater. Apple Vision and the original MobileCLIP-S2 models provide on-device search; their respective notices and model licenses must accompany distribution. Adapted Tendedero contributions include clipboard capture by Anubhav-Rai, language/copy feedback, the menu count and the image-search bridge.
