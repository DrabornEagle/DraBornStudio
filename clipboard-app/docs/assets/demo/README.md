# Demo media

These files show clipboard-app 1.7.2 with example content, not personal clipboard
history. The macOS screenshots and silent videos were captured through Computer
Use from an isolated demo fixture using the production native UI components.
An opaque neutral backdrop makes the normally transparent shelves legible in
window captures. Application behavior and interface controls are unchanged.

The videos preserve the timing of sampled live UI captures, encoded as H.264
MP4 at 1280×800, 10fps. They are 16.3s and 17.3s long and contain no audio.
English and Turkish WebVTT tracks describe the actual keyboard actions.
No external-paste behavior is demonstrated by the isolated fixture.

`windows-library.png` is a genuine installed Windows1.7.2 capture from
[native CI39307655801](https://github.com/orkunisitmak/clipboardline/actions/runs/39307655801),
using synthetic fixtures and example.com links.

All captures were visually reviewed for private content before publication.
