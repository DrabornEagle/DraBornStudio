# Coconut brand · DrabornEagle

The Coconut-app edition uses a new coconut mark, navy surfaces and mint interaction accents.

- Web asset: `web/assets/coconut.png`
- Native app assets: `Resources/Brand/Coconut.png`, compatibility image names in the same folder, and `Resources/NashiIcon.icns`
- Light/dark palette: `web/assets/coconut.css`, `Sources/NashiApp/DesignSystem.swift`, `windows/Nashi.Windows/Theme.cs`
- The PNG mark was generated with the built-in image generation tool; native formats are encoded from that same asset. Original product logos are not used in the Coconut interface.

Prompt: a premium isolated halved coconut app mark for Coconut, with creamy white interior, warm brown shell, copper rim and a fresh green leaf; rounded three-dimensional shape, soft studio lighting, transparent alpha, recognizable at small sizes; no text, face, background tile or watermark.

The module and executable names remain compatible with the imported sources. Desktop distributions need their own native-host validation and signing before release.
